# Xiaobai Grok

AstrBot 插件。用 Grok 账号 OAuth 登录，在管理页查询订阅额度，并把 Grok 作为对话模型提供商。

不包含图片生成、图片编辑、视频生成和网页搜索工具。对话时如果消息里带了图片，仍会作为模型输入交给 Grok 理解。

## 使用

1. 在 AstrBot 里用本 ZIP 安装，重载插件。
2. 打开插件页面「授权与设置」，连接 Grok 账号。
3. 在模型提供商里新增 **Xiaobai Grok**，添加 `grok-4.7`，在会话里选用该模型。
4. 额度在同一页面点「查询额度」。
